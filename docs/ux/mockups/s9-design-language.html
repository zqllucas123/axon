Axon 视觉设计语言 v0.1

参照 Codex 桌面端：暖灰底、极低对比描边、零阴影、1.6px 线性图标、近黑主按钮。目标是「安静的工具」——界面本身不抢注意力，状态靠位置与极小色块表达。

1. 表面与描边

三层暖灰：侧栏最暗、画布居中、卡片最亮。分层只用 1px 描边，全局不用投影——阴影会让密集信息界面显脏。

--bg-sidebar#f2f1ee
--bg-canvas#fcfcfb
--bg-elev#ffffff
--bg-sunken#f6f5f2
--line#e7e5e0
--line-strong#d8d5ce
--bg-active#e6e4df
--accent#2b2a27

2. 语义色（一律降饱和）

状态色只用于 7px 圆点、22px 标签、5px 进度条，永不铺大面积。运行中 = 土黄而非蓝，避免与「链接/可点」混淆。

--sem-run 运行中#a8791a
--sem-ok 完成/采纳#4a7a52
--sem-wait 等待/排队#6f6e84
--sem-err 错误/待批#b0473b
running parked 已采纳 待批准 context: none /0/1/2

3. 字阶与半径

正文 14px / 会话 15px / 标题 17–22px / 元信息 11–13px。半径梯度：标签 6 → 按钮 8 → 卡片 12 → 面板 16 → 气泡 20。

4. 图标

统一 24 视窗、1.6px 描边、圆头圆角、currentColor；尺寸只有 14 / 16 / 18 / 20 四档。不用填充图标，不用双色。

5. 组件

会话流只有六种元件：用户气泡、助手正文、活动行、折叠块、卡片、输入区。新增信息优先做「卡片」而不是新区块，避免版式发散。

用户气泡：右对齐、sunken 底、20px 圆角

助手正文：无气泡、无头像，直接铺在画布上，靠留白分段。

活动行：读文件 / 用时 55 秒
折叠块：thinking / 工具输出
默认收起，只有用户主动展开。
卡片工具 / 审批 / 协作 / 错误ok
头 = 图标 + 名 + 路径 + 状态标签；身 = 内容；脚 = 动作。四种卡片共用同一骨架。
输入区：16px 圆角、单描边、底排放模式开关与发送圆钮

6. 三条硬规矩

这三条是把 Codex 风格落到 Axon「多分身」场景的关键，违反就会变成另一个产品。

① 分身身份靠位置，不靠颜色
侧栏树缩进 + 引导竖线表达父子；不给每个分身分配主题色（3 个以上就失效）。
② 一屏一个焦点分身
会话屏永远只渲染当前选中分身的流；跨分身信息走账本（S4）与收件箱（S5），不做混流 EventLog。
③ 需要你决策的东西永远有 chip
待批数 / 预算档 / 账本待表态常驻顶栏右侧，任何屏都能一眼看到并点进去。

7. 数据标注机制

原型里蓝色虚线标注 = 已有协议支撑；红色虚线标注 = MX 缺口清单条目（G1~G9）。任一屏按 ⌘/ 或点顶栏眼睛图标切换。

示例：agent.messages 已实现G2.4 approval.request 未发射

新建会话

这次要做什么？

先说任务，再决定要不要组队。多数任务不需要一个功能全面的团队——Axon 默认用内置引擎单兵完成，中途发现做不动了再叫人。

例如：把 apps/api 的支付回调改成幂等，回调表加唯一键…
怎么执行G10.1 session.create 的 executor 字段
选一个团队G10.2 team.list 去团队管理 →
主架后测
全栈小队
主控 + 架构师 + 后端实现 + 测试工程师。跨层改动的默认编队。
4 成员并发 3$1.50 上限
主后测
测试双人
实现 + 测试成对推进，只补测不改架构。

评审小队
只读团队：读码、评审、出文档，全员禁止写盘。
3 成员并发 2全员只读
不确定要不要组队？
直接用内置引擎开始。跑起来之后如果任务比想象的大，会话里随时能「叫人」——把当前上下文原地升级成团队会话，已产生的消息不丢（ForkMode 决定新成员能看到多少）。
改错别字 → 内置引擎 查个协议怎么写 → 内置引擎 跨三层的重构 → 全栈小队 只想要评审意见 → 评审小队
会话 = 一等公民
任务会话的题目
执行方式引擎 / 团队 / 临时
工作目录cwd
预算继承团队或全局

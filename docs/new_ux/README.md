# Axon 新版 UX 原型

这组原型以 `docs/ux/00-信息架构与屏幕清单.md`、`docs/ux/01-视觉设计语言与高保真原型.md` 和 `docs/ux/02-团队与会话模型.md` 为设计基准，目标是让界面体现 Axon 的真实产品模型，而不是调试控制台或装饰性卡片集合。

## 页面职责

| 页面 | 产品文档中的职责 | 原型 |
|---|---|---|
| 新建会话 | S0：默认单兵，需要时选择团队 | `01-home.html` |
| 会话总览 | S1：跨会话查看状态、成本和待处理事项 | `07-session-overview-simple.html` |
| 团队管理 | S3：团队、Agent 成员、Agent 类型三层关系 | `08-teams-simple.html` |
| 收件箱 | S5：跨会话聚合审批、提问和采纳请求 | `09-inbox-simple.html` |

## 视觉约束

- 三层暖灰表面、1px 描边、无投影，沿用 Codex 的克制层级。
- 语义颜色只表达运行、等待、完成和错误状态，不用于装饰大面积背景。
- 左栏只放全局导航与会话列表；会话成员树、团队和账本属于右侧会话检视区。
- 真实产品模型中的 `Session / Team / Agent / Agent 类型` 分层在界面中保持一致。
- 设计稿使用 `assets/pro.css` 与 `assets/pro-shell.js`，保持原型可独立打开。

入口：打开 `index.html`，从四个主页面开始评审。
